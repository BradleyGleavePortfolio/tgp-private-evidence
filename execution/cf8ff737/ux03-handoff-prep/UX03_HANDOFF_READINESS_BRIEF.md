## 2. Locator trust boundary — what the accepted source actually establishes

1. **The 6-digit pairing code is the handoff credential.** `pair/redeem` is unauthenticated and returns coach-bound Supabase access/refresh tokens. Therefore the code must never enter a URL, deep link, analytics event, log, clipboard-shared "setup address", or mirror telemetry. This is already honoured by the mirror ("never logged, never sent to telemetry") and must remain the invariant for any UX-03 slice.
2. **No opaque, non-authorizing setup locator exists in C1.** `pair/current` and `pair/session` are bearer-only owned-setup lookups for the phone; neither is a shareable address. J4's "trusted TGP setup address containing at most a non-authorizing opaque locator" is therefore **not implementable from accepted source**. Its issuance semantics (what a locator may resolve, whether `pair/redeem` may ever accept anything but the code, TTL/retirement) sit inside the G3 auth-owner freeze (revocation / attribution / capability / transport). **Genuine new security-authority decision — not made here, not a routine choice.** Until then J4 is exactly the spec's fallback: explain "Continue on your computer", then the existing J5 code path, which needs no URL.
3. **`import_intent_id` is correlation, not authority.** Consumers may persist and echo it (`pair/session`) but must not derive eligibility, Start, connection, or result state from it. `setup_nonce` is a client-saved idempotency/recovery key (persisted before init, X1/E01) — it lets a coach recover an owned attempt via `pair/init`/`pair/current`, it does not authorise anything.
4. **`paired` means only "this code was redeemed for this coach's account".** It does not mean installed-and-running, capability-known, or previous-platform-connected. Any checklist line beyond that reads "not yet known" (CQ-08 fallback).
5. **Sign-out vs revocation stays asymmetric and truthful.** Phone sign-out (`authActions.ts` + `#291` purge + UX-01 list entry) clears local state and makes no revocation claim; there is no revocation/disconnect endpoint (S7 map "Missing"; CQ-15). No UX-03 copy may say the computer/extension was signed out or disconnected.
6. **Local state is never server eligibility.** UX-01 `ready && null` and the mirror are presentation inputs only; ownership mismatch (E14/E16) needs a server binding check that does not exist yet.
