# Contract questions: UX-01 Importer Journey & State Architecture

Companion to `CANONICAL_MOBILE_JOURNEY_SPEC.md` and `STATE_AND_EDGE_CASE_MATRIX.md`. Source-only; T4 cumulative planning artifact. These are questions the **mobile journey needs answered by the authoritative backend generator / auth owner / extension owner before consumer code is written**. None is a defect; all are missing execution steps already named by PLAN (decisions 1–6, open decisions table) or the S7 map (“Missing”). Mobile design proceeds on every question; mobile implementation of the affected screen waits.

Conventions: **Current fact** = pinned source within the inspected boundary (public mobile main `a5933fd6`, public mobile PRs #289–#294, backend PR526/528/529 per S7 map); "none" means not present in that boundary and canonically unproven, not absent everywhere (spec addendum, Current-state qualification). The eventual mobile code base is the accepted S6 successor of baseline `d51a191098f483cea9abec6cc7e9f3beffd18c06`, which already carries #289–#292. **Owner** = the lane that must freeze the answer. **Gate** = readiness stage at which the answer can exist. **Truthful fallback** = what mobile may render until the answer lands (never a guess). **UX** = official label of the consuming job.
