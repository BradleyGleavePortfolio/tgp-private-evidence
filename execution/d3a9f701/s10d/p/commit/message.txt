test(scout): state shipped-source invariants instead of the empty-disk assumption

The native-families, manifest-registry, mapping-spec and facts coverage specs
asserted that no source package ships on disk. They now assert the invariant
that must hold for any shipped set: every shipped rule set names only families
of its shipped spec, every shipped manifest has a matching spec digest, shared
id spaces are declared validly, and the coverage packages equal the shipped
manifests for the slug. A new source can then land without editing core tests.
