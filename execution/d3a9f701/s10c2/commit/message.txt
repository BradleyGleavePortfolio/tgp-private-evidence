feat(contracts): publish the run declaration and observation routes

The importer contract now lists POST /scout/runs/declaration and
POST /scout/runs/observation, mounted by the scout module through the
observation module. The contract spec pins their bearer security, request and
response schemas, response codes and DTO fields. The OpenAPI document is
regenerated from the script. The contract version is unchanged because the
change is additive, following the S8-F and S9-C precedent.
