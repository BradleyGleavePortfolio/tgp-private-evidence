## 2. SOURCE assessment

### 2.1 Verifier (`verify.sql`, unchanged bytes since 41f4 — applicability re-reviewed, not assumed)
- L147–150: `has_table_privilege(api_role, format('public.%I', t), priv)` over `SELECT, INSERT, UPDATE, DELETE, TRUNCATE` for `anon`, `authenticated`. Per the PostgreSQL 17 documentation, `TRUNCATE` is an allowable privilege type for `has_table_privilege` and `PUBLIC` "can be used to grant a privilege to every role on the system" ([functions-info](https://www.postgresql.org/docs/17/functions-info.html), [ddl-priv](https://www.postgresql.org/docs/17/ddl-priv.html)); member roles "granted membership with the INHERIT option automatically have use of the privileges" of the granted roles ([role-membership](https://www.postgresql.org/docs/17/role-membership.html)). So the loop is effective over direct, PUBLIC and inherited-membership grants for a role with inheriting memberships. Row security "can be specified to apply to ALL commands, or to SELECT, INSERT, UPDATE, or DELETE" and "operations that apply to the whole table, such as TRUNCATE and REFERENCES, are not subject to row security" ([ddl-rowsecurity](https://www.postgresql.org/docs/17/ddl-rowsecurity.html)) — the rationale in the header (L28–31) is correct: RLS is not a compensating control for TRUNCATE.
- L149 `format('%I: %s still holds %s', t, api_role, priv)`: `%I` "treats the argument value as an SQL identifier, double-quoting it if necessary" ([functions-string](https://www.postgresql.org/docs/17/functions-string.html)) → `"MuxProcessedEvent"` quoted, `coach_ltv_peak` unquoted. Confirmed in real output (§3.3).
- L225–230: single RAISE line `S1-DB-01 VERIFY FAILED (<n> exposure problem(s); <m> allowed-path problem(s)): EXPOSURE: <p1>; <p2>… || ALLOWED-PATH: …`. Real grammar confirmed (§3.3). Therefore in a protected DB with one TRUNCATE-only grant the message must be `…(1 exposure problem(s); 0 allowed-path problem(s)): EXPOSURE: "MuxProcessedEvent": <role> still holds TRUNCATE`, and with a PUBLIC grant two items anon-then-authenticated joined by `; `.
