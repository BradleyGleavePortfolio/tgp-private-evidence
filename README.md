# TGP Private Execution Evidence

Private preservation of TGP audit reports and their candidate identities, created under the operator's instruction to retain every returned audit report in GitHub. This repository is not a public disclosure channel or a replacement for canonical product/governance repositories.

Reports are organized by execution date, lane, audit round and independent reviewer. Negative, blocked and passing reports are all retained; revised reports use explicit revisions rather than erasing prior findings.

Each publication records the source candidate, report identity and evidence limitations. Audit completion does not mean merge, deployment, enablement or customer acceptance.

Never commit credentials, secret values, customer records or raw sensitive runtime logs. Detailed audit findings remain private; the public `tgp-agent-context/LAST_OPERATOR_STATE.md` carries only concise current status and references.
