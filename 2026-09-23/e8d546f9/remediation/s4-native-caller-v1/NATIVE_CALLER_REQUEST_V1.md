## 1. The defect being corrected (ruling §Decision; V61 request §5.1)

The accepted `bash -c 'cd …; if bash launcher/s4-r6-launch-v6.sh; then rc=0; else rc=$?; fi; printf "launcher exit=%s\n" "$rc"; exit "$rc"'` blocks on the launcher's exit. When the launcher SELF-HOLDs (standby holder lost **and** one respawn failed while survivors are unresolved: `quarantine_exit` → `publish_and_exit QUARANTINED_SELF_HOLD 12` → `exec -a <token>-SELF bash -c 'trap "" TERM INT HUP; while :; do sleep 60 9>&-; done'`, launcher lines 299–315, 216–221) the process never exits, so "actual normal exit", "bounded observer return" and "identity-bound retained owner" collapse into a single indefinite hang with no receipt, and any outer bound that KILLs the hang would destroy the last exclusion owner. The ruling requires the three facts to remain separate, no unbounded wait, no KILL of the last owner, no faked exit 12/success.

## 3. Bound statement (unchanged 3300 + 45 → 3422 qualified allowance)

`OBSERVE_S = OUTER_S(3300) + GRACE_S(45) + LAUNCHER_POST_S(77) = 3422 s` — identical to `bounds.worst_case_s` published by the launcher with the same qualification (sum of declared phase allowances; `mv`/log lines not enclosed). Observer worst case = 3422 + 127 (one cancel allowance: 45 + 77 + 5) + ≤ 10 s (census/record reads under `timeout`, receipt) ≈ **3559 s**. This bounds the *observer*, not the launcher: the caller makes no claim that every execution ends within 3422 s — a launcher alive after that is reported, not terminated.

## 4. Transport (same as Stage 1; no new requirement)

The current `bash` tool caps a call at 900 s (platform supervisor TERM→KILL of the call's group) and tears down the call's process group on return, so the native caller must be run through the accepted transport-only detachment: `setsid -f bash -c '<wrapper>' _ native-caller-v1.cmd <exit receipt> </dev/null > <log> 2>&1` exactly as `s4-control-prep/TRANSPORT.md` T1 (with `stage1-caller.cmd` → `native-caller-v1.cmd`, sha256 pinned in `SHA256SUMS`), T2 polling in ≤ 840 s slices, T3 collection. Topology under the transport: wrapper (session leader W) → `bash native-caller-v1.cmd` → caller (`set +m`) → launcher (pgid W ≠ launcher pid) → runner in its own `setsid` session. The transport's exit receipt records the caller's **observer** return; the caller's own receipt records the launcher's **actual** exit separately; the launcher's `SUPERVISOR_RECORD.json` remains the primary record. Three distinct artefacts for the three facts.
